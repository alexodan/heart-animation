# React Motion Lab – Heart Animation

This project is a small playground I’m using to learn and practice UI animations in a modern React stack.
The first experiment is a simple heart animation (built with Vite + React) focused on timing, easing, and subtle motion details.

Eventually, the objective of this repo is to grow into a collection of little animation demos.

## 🔍 What this project is

A Vite + React project set up as a lightweight sandbox for UI animations.

### 1st Animation: Heart component (e.g. like/favorite interaction)

Taken from Josh Comeau's course whimsical animations

Focuses on:

- Micro-interactions
- Smooth transitions
- Easing and timing curves
- Reusable animation patterns - maybe
